Live mapper QA

Hydrates the real data stack against the live proxy, captures sample ids, then runs each window.NHL.* mapper on real payloads and checks the resulting view-model field-by-field. This is the gate api-health (reachability) and mappers-test (synthetic units) don't cover — does the real shape map correctly? Watch the EDGE section especially.

Booting data stack…
Status key — PASS: mapper returned a view-model with every checked field populated · PARTIAL: mapped, but some fields are null/empty (listed) · FAIL: mapper returned null / threw / empty against the live payload · SKIP: no sample id (e.g. off-day → no game feeds, off-season → no live game).
In the design preview there is no proxy, so the stack stays on mock and every live check SKIPs — deploy to Cloudflare and reload for real results.
